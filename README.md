# Estructuras Lineales - Pilas en Java

Este repositorio contiene las implementaciones de estructuras de datos lineales (**Pila Simple** y **Pila Dinámica** utilizando Nodos) desarrolladas para la materia de Estructura de Datos.

## Lenguaje de programación utilizado
- **Lenguaje:** Java
- **Versión:** Java 17 (JDK 17) o superiorPrueba de Operaciones con Pila Dinámica:

## Pasos para compilar y ejecutar

1. Abre una terminal o consola de comandos.
2. Navega hasta la carpeta raíz de este repositorio.
3. Compila todas las clases Java del proyecto:
   ```bash
   javac *.java

## Ejecuta la clase principal para probar la Pila Dinámica:
java Main
##O para probar la Pila Simple:
java lanzador_pilasimple
